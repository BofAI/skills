# x402 Payment Skill

Use `wallet-cli x402` through `@tron-walletcli/wallet-cli@4.14.0`.

Read [SKILL.md](SKILL.md) for the workflow and [wallet-cli setup](../wallet-cli/README.md)
for the shared CLI dependency and account configuration. Skill version: 3.0.0.

Install this release candidate explicitly:

```bash
npx skills add https://github.com/BofAI/skills/tree/release_v3.0.0 --skill x402-payment
```

The Skill installer does not install the CLI. Preview and confirm any mainnet payment.
